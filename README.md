# 3D Creative Apple Website

An Apple-inspired 3D product website built with React, Three.js, GSAP, Zustand, and Tailwind CSS.

## Tech Stack

- **Frontend / Framework:** React, Vite, Tailwind CSS
- **3D & Animation:** Three.js, React Three Fiber, React Three Drei, GSAP (ScrollTrigger)
- **State Management:** Zustand
